# @citadel-app/ui

The official design system and component library for Citadel. Built with React, Radix UI, and Tailwind CSS.

## Features

- **Premium Components**: Highly interactive, accessible UI components.
- **Design Tokens**: Standardized colors, spacing, and typography using Tailwind.
- **Visual Atoms**: Buttons, Inputs, Dialogs, and navigation primitives.
- **Lucide Integration**: Native support for themed icons.

## Installation

This package is part of the Citadel monorepo.

```bash
npm install @citadel-app/ui
```
