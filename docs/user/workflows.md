# Advanced Workflows: Patterns for Success

**TL;DR**: Citadel is a blank canvas. Discover proven patterns like Zettelkasten and Project Tracking to scale your knowledge.

## 1. The Zettelkasten Method
Zettelkasten is a system of "slip-boxes" for interconnected, atomic notes. It is the primary method for long-term knowledge growth in your **Keep**.

> [!TIP]
> This is a deep topic. For the full philosophy, see our [Conceptual Guide on Zettelkasten](../concepts/zettelkasten.md).

- **Atomic Scrolls**: Use the `Note` type to create small, single-idea scrolls.
- **Discovery**: Use the **Tag Graph** to find unexpected connections between unrelated scrolls.

## 2. Project Tracking (The Citadel Way)
Combine notes, code, and visual tools.

1. **Create a Project Entry**: This is your "Main Hub" for a project.
2. **Link a Kanban Board**: Manage tasks directly from the project entry.
3. **Attach Code Snippets**: Store your architectural decisions and key functions alongside the project description.
4. **Embed Whiteboards**: Use Excalidraw for the project roadmap and UI designs.
5. **Integrated Git**: Commit your project notes alongside your actual source code.

## 3. The "Inbox" Workflow
Don't let ideas slip away.
- **Archive**: Once a project is finished, move its folder to an `Archive/` directory to keep your **Archives** clean.
