# Productivity: Zen Mode and Search

**TL;DR**: Work at the speed of thought with a distraction-free UI, deep full-text search, and core keyboard shortcuts.

## 1. Zen Mode (Ctrl+Alt+Z)
When it's time to deep work, enter **Zen Mode**.

- **Atmospheric UI**: The sidebar, status bar, and title bar disappear, leaving only your content.
- **Focus Backgrounds**: Subtle, animated gradients help keep your focus centered.
- **Minimalist Interaction**: Only the essential editing tools remain visible.
- **Safety Exit**: Press `Ctrl+Alt+Z` again or look for the "Maximize" icon in the bottom right to return to the full workspace.

## 2. Global Search
Search across your entire library directly from **The Archives**.
- Create complex queries using the **Query Syntax**.
- Filter by type (e.g. `type:paper`) or tag (e.g. `tag:work`).
- Instant results with debounced filtering.

## 3. Keyboard Shortcuts
Master these to stay in the flow:

| Action | Shortcut |
|--------|----------|
| **Toggle Zen Mode** | `Ctrl + Alt + Z` |
| **Go Back** | `Alt + Left` (standard browser) |
| **Go Forward** | `Alt + Right` (standard browser) |
| **Toggle Theme** | Action button in Title Bar |

> [!NOTE]
> Additional power-user shortcuts are being migrated to the custom Command Palette in a future update.

## 4. Deep Search
Searching in Citadel goes beyond just filenames.
- **Full-Text Search**: Finds keywords within your actual Markdown content.
- **Metadata Filters**: Use prefixes like `type:paper` or `tag:work` in the search bar.
- **Regex Support**: For the power users who need surgical precision.

- **Custom CSS**: Developers can add their own CSS snippets in Settings to tweak the UI to their liking.
