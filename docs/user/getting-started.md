# Getting Started with Citadel

**TL;DR**: Initialize your first Keep, connect with GitHub, and learn the layout of your new "Second Brain."

## 1. Installation

Citadel is currently available as a desktop application. 

- **Download**: Grab the latest release for Windows, macOS, or Linux from our [GitHub Releases](https://github.com/iwannabebot/citadel/releases) page.
- **Run**: Install the application and launch it.

## 2. First Launch: The Welcome Screen

When you first open Citadel, you'll be greeted by the **Welcome Screen**. This is where you connect your identity and prepare your first workspace.

### Connecting GitHub (Recommended)
Citadel uses GitHub for seamless synchronization and repository management.
1. Click **Sign in with GitHub**.
2. A browser window will open, or a **Device Code** will appear. 
3. Enter the code on GitHub to authorize Citadel.
4. Once authorized, Citadel will automatically fetch your profile.

### Going Offline
If you prefer to keep everything strictly local without any cloud integration, click **Continue without login**. You can always connect an account later in Settings.

## 3. Creating Your First Keep

A **Keep** is a folder on your computer that Citadel manages. 

### Starting from a Template
Click **Create New Keep** to open the Keep Builder. We recommend starting with a **Preset**:
- **Software Engineer**: For tracking coding problems, system designs, and technical RFCs.
- **Academic Researcher**: Focus on paper annotations, standards, and literature review.
- **Product Manager**: PRDs, User research, and project roadmaps.
- **Creative / Minimalist**: Pick from visual scriptwriting or plain markdown notes.

### Cloning an Existing Repo
If you already have a repository on GitHub that you want to use as a Keep:
1. Select **Open Remote Repo**.
2. Browse your repositories and select the one you want to clone.
3. Choose a local folder for the files.

## 4. Navigating the Keep

Once your Keep is ready, you'll enter the **Main Layout**. Here’s a quick map:

- **Activity Bar (Left)**: Switch between the Archives, Scriptorium, and utilities.
- **The Archives**: Your primary way to find and open scrolls.
- **Status Bar (Bottom)**: See your current Bastion status (Git), sync progress, and app version.
- **Navigation Controls**: Use the arrows in the **Title Bar** to move back and forth through your history.

## 5. The Onboarding Tour

If this is your first time, a **Highlight Tour** will guide you through the key areas of the UI. Follow the sparkles!
