# Citadel Glossary

This glossary defines themed terms and concepts used throughout the Citadel application.

### A

**The Archives (formerly Library Browser)**
The primary navigation interface in Citadel. It allows you to search, filter, and sort all **Scrolls** in your **Keep** based on their metadata and type.

### B

**The Bastion (formerly Git/Sync)**
The historical tracking and synchronization model of Citadel. All changes are tracked via version control, allowing for local-first privacy with optional cloud sync.

**Codex**
A specific entry type that serves as a high-level index or a detailed technical record within your Archives.

### E

**Entity**
A conceptual term for a **Scroll** when viewed as a database object. Citadel's "File-as-Entity" model means files are treated as queryable records.

### F

**The Forge (formerly REPL)**
An interactive programming environment. The Forge allows you to execute code in secure, isolated Docker containers.

**Frontmatter**
The YAML block at the top of a Markdown file. It contains the metadata that Citadel uses to track and organize the Scroll.

### K

**Keep (formerly Workspace/Vault)**
A folder on your disk that Citadel has been authorized to manage. A Keep is the central repository for all your Scrolls, assets, and history.

### O

**The Oracle (formerly AI/Orchestrator)**
The knowledge retrieval and assistance system. The Oracle uses **RAG** to provide context-aware answers from your Keep.

### R

**RAG (Retrieval-Augmented Generation)**
A system where the Oracle "retrieves" relevant Scrolls from your Keep to answer questions with better accuracy.

### S

**Scroll (formerly Entry)**
The fundamental unit of data in Citadel. Every file (Markdown, PDF, etc.) is a "Scroll" with an associated ID and metadata.

**The Scriptorium (formerly Notebooks)**
The specialized creation suite for writing rich text, code snippets, and mathematical notation.

**The Scribe**
The LaTeX-optimized editor within the Scriptorium.

**The Sight (formerly YouTube Feed)**
The aggregate view of technical video content and lectures from across the collective.

**The Signal (formerly RSS Feeds)**
The broadcast receiver for external technical journals, papers, and blog updates.

### W

**The War Room (formerly Kanban/Whiteboards)**
The visual strategy and project tracking area. Use infinite whiteboards (**The Canvas**) for brainstorming and Kanban boards for workflow management.

**The Watchtower (formerly System Status)**
The monitoring dashboard for all Citadel services, Docker containers, and hardware performance.

**The Workshop**
The integrated terminal and developer toolset accessible via right-click or quick keys.

### Z

**Zen Mode**
A distraction-free UI state that hides all sidebar and navigation elements, focusing entirely on a single Scroll.

**Zettelkasten**
A knowledge management method based on "atomic notes" and heavy interconnectivity. Citadel is designed to facilitate this workflow natively.
