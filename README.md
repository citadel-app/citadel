## 🚀 Quick Features

- **Local-First:** Your data is stored as plain Markdown on your disk in a **Keep**.
- **The Bastion:** Industry-grade versioning and collaboration via GitHub/GitLab.
- **The War Room:** Brainstorm with infinite whiteboards and Kanban boards.
- **External Knowledge:** Aggregated RSS and YouTube feeds directly in your workspace.
- **The Oracle:** Privacy-first AI for summarizing and querying your knowledge.
- **The Forge:** Execute code snippets directly within your workspace using local isolated environments.
