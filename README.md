Citadel is a productivity application that combines the durability of local Markdown files with structured UI elements. It is designed to help developers and power users organize interlinked digital objects without relying on deep hierarchies.

## Features

- **Markdown-First Workflow:** Your data is stored as plain Markdown files on your local file system, acting as a future-proof source of truth while being enhanced by a structured UI.
- **Embedded Whiteboards:** Generate, store, and edit diagrams visually using fully integrated Excalidraw whiteboards.
- **Integrated Feeds:** Aggregate RSS and YouTube feeds locally to connect external information directly to your notes and keep everything in one structured place.
- **Local AI Assistance:** Leverage optional, privacy-first AI features powered by locally runnable Small Language Models (SLMs) to summarize or query your knowledge base.
- **Extensible Data Model:** Customize object types, metadata, navigation, presentation, and linking behavior. Create a flexible structure that adapts to your own specific mental models rather than relying on strict folder hierarchies.
- **Code REPLs:** Execute embedded code snippets safely using isolated local Docker containers directly within your workspace without leaving the app.
- **GitHub Integration:** Authenticate seamlessly via the GitHub Device Flow. You can easily clone, fork, or open repositories using Citadel's automated deep linking functionality.
- **Hackable Architecture:** Built with an opinionated but highly extensible core. Adjust the application's behavior through configuration and presets to build a custom toolchain.
